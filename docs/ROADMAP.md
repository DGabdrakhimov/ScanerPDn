# План выпусков — спецификация 1.3

Обновлено 12.10.2026. Подробная матрица «проверка → норма → релиз → граница результата» и критерии приёмки: [SPEC_CHANGE_1_3.md](SPEC_CHANGE_1_3.md). Правовые блоки отчёта: [SPEC_CHANGE_1_2.md](SPEC_CHANGE_1_2.md).

Это план разработки. Настоящее изменение документации не добавляет функции в исполняемый пакет 0.1.0rc1. Автоматическое выполнение будущих этапов без активной задачи не обещается.

| Этап | Объём | Часы / недели при 30 ч в неделю |
|---|---|---|
| R1 | CLI, семь технических правил, HTTP/HTML, инвентаризация, JSON/HTML; закрытие оставшихся условий приёмки | 90 / 3 |
| Уточнение 1.2 к R1 | Точная правовая привязка каждого результата, разделение технического и юридического статусов | 18 / 0,6 |
| R2 | Браузерный CLI, DOM, элементы согласия, сценарии cookie, видимые запросы | 90 / 3 |
| R2.1 | Извлечение HTML/PDF с текстовым слоем/DOCX; сопоставление содержания с наблюдениями сайта | 90 / 3 |
| R2.2 | Импорт уведомления РКН и изменений; сопоставление по целям обработки | 90 / 3 |
| R3 | Локальный интерфейс, история, источники и расхождения; только loopback | 60 / 2 |
| R4 | Размещённый пилот, изоляция, расписание, адаптер реестра при доступности | 120 / 4 |
| R5 — опция | OCR, внутренние подтверждения, экспертная оценка сложных расхождений | 180 / 6 |

Всего 738 часов, около 25 недель с начала полного объёма; без R5 — 558 часов, около 19 недель. Это проектная оценка, а не оставшийся срок и не фактически затраченные часы. QA и участие владельца продукта учитываются отдельно. Базовые ориентиры 16 недель заменены этой оценкой для расширенного объёма. Идентификаторы R2.1/R2.2 обозначают этапы; номера версий пакета фиксируются при выпуске.

R1 сохраняет исходную границу: достоверные поверхностные наблюдения без эксперта. Наличие checkbox не является самостоятельным универсальным требованием закона. Отдельное оформление согласия, содержание документов и правомерность конкретного процесса — разные проверки. Импорт уведомления не зависит от доступности публичного реестра; сканер не отправляет уведомления в РКН.

Полные отраслевые профили, внутренние меры ФСТЭК и иные отложенные контроли перечислены в разделе 37 спецификации 1.3; они не включены молча в оценку R5. Перед выпуском остаются обязательны применимые условия приёмки, включая невыполненные проверки окружений и публичных сайтов для R1.
