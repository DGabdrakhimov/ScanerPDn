# Отчёт о проверке 0.1.0rc1

Дата: 09.10.2026. Среда: Linux, Python 3.12.14, OpenSSL 3.5.8.

- 225 тестов unittest, все успешно. Полный список: `test-run.txt`.
- 175 сценариев C01–C07: для каждого правила 10 положительных, 10 отрицательных, 5 пограничных примеров.
- 50 дополнительных тестов: запрет адресов/портов/userinfo, DNS deadline/rebinding, pin и peer, редиректы, robots, Retry-After, scope, лимиты, отмена, экранирование, очистка данных, команды и файлы.
- HTTP/TLS-тесты используют реальные сокеты локального учебного сервера. Разрешение loopback подменяется только в тестах; пользовательского флага обхода в продукте нет.
- Проверены TLS: доверенный сертификат, недоверенный, истёкший и неверное имя. При ошибке тело не считывается.
- Wheel установлен через `pip install --no-index` в новый venv без runtime-зависимостей. В этом venv выполнены все 225 тестов, `--version`, `doctor`, `rules list` и offline render.
- Синтетический отчёт: `examples/demo`. Проверки не обращались к example.org; в отчёте стоит явная отметка демонстрации.
- Внешняя проба CLI к example.org завершилась DNS error, partial/grey и кодом 3. Среда не обеспечивает необходимую прямую сеть; успешный полевой прогон не заявляется.
- Производительность только синтетического ядра: `benchmark.json`; это не замер сети и не подтверждение SLA.

Независимый набор для измерения precision/recall не применялся. Docker, WSL2 и 10 публичных сайтов не проверены. Статус кандидата сохраняется. Приёмочные условия перечислены в TRACEABILITY.md.
