# Проверка кандидата 0.2.0rc1

Дата: 14.10.2026. Среда: Linux, Python 3.12.14. Набор: 264 теста, **263 пройдены, 1 пропущен**, ошибок нет. Полный журнал: `test-run-r2.txt`. Старые `test-run.txt` и `test-run-rc2.txt` относятся к предыдущим выпускам.

Проверены:

- регрессия R1: правила, транспорт, SSRF/DNS, TLS, robots, ограничения, приватность, формат отчёта;
- правовые профили политики/согласия/неизвестного документа, поздний конфликт подписей, отсутствие автоматического юридического вердикта;
- логика повторяемости B03/B04, неполные сценарии, различение попытки и полученного ответа;
- блокировка POST, query, внешней области и приватного DNS браузерным шлюзом в изолированных тестах;
- маскирование значений и URL, HTML-экранирование, сохранение R1 при ошибке R2, сравнение и чтение старой схемы;
- валидация синтетических R1 и combined по JSON Schema 1.1;
- сборка wheel и установка в чистое окружение без сети/сторонних runtime-библиотек, `--version`, `doctor`, офлайн-демонстрация, `compare`;
- `doctor --browser` без Playwright возвращает признак отсутствующего модуля; с установленным Playwright и без Chromium сообщает ошибку запуска. Это проверка обработки отказа, не успешный запуск браузера.

**Не проверено:** успешный запуск настоящего Chromium, полноценное выполнение DOM/S0–S3, реальный исходящий трафик Chromium, WSL2, Python 3.14.4, контейнерный R2 и публичный пилот на i.fors.ru. Загрузка Chromium 156.0.8078.4 / headless shell v1248 через Playwright 1.64.0 завершилась ошибкой повреждённого/пустого архива. `tests/test_browser_integration.py` поэтому явно пропущен.

До стабильного выпуска требуется выполнить этот интеграционный тест без пропуска, проверить сетевую изоляцию браузера и провести пользовательский пилот. Наличие исходников и пройденных модульных тестов не заменяет эти условия. Кандидат предназначен для совместной проверки R1/R2, не для утверждения юридического соответствия сайта.
