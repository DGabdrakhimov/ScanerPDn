# R2 0.2.0rc1 — 14.10.2026

Тестовый кандидат. Стабильная приёмка R2 не завершена.

## Добавлено

- Опциональный Playwright/Chromium; команды `--mode r1` и `--mode combined`.
- Правила B01–B06: документы после JavaScript, связи выбора с подписью/ссылкой, явные совместные формулировки, предустановленный выбор, рекламные признаки, сценарии cookie.
- S0–S3 в чистых контекстах, по две попытки; состояния после согласия и отзыва, раздельные попытки и полученные ответы.
- Отдельный сохранённый отчёт R1 в совместном запуске, изолированный процесс браузера с предельным сроком.
- Команда `doctor --browser`; офлайн-сравнение двух JSON с HTML-результатом.
- Схема 1.1: точные нормативные профили, условия применимости и недостающие доказательства. Исправлен выбор типа документа при конфликтующих подписях.
- Пояснение, что sha256-адрес — замаскированный идентификатор, не открываемая ссылка.
- Подробный README для Windows/WSL с объяснением команд; дополнение 1.5 к спецификации.

## Совместимость

C01–C07 сохраняют технический смысл. JSON схемы 1.0 можно переоформлять; юридическая привязка не добавляется задним числом. R1 работает без сторонних runtime-библиотек. R2 требует отдельной установки Playwright 1.64.0 и соответствующего Chromium. Старую папку R1 и отчёты сохраняйте; устанавливайте R2 в новое окружение.

## Проверка и ограничения

263 автоматических теста пройдены. Один интеграционный тест с реальным Chromium пропущен: загрузка бинарного браузера в среде сборки завершилась ошибкой архива. Python сборки — 3.12.14/Linux. WSL, Python 3.14.4, контейнер и реальный i.fors.ru этим кандидатом здесь не проверены. Нельзя считать браузерный режим подтверждённым полевым тестированием.

Сценарии поддерживают ограниченный список однозначных кнопок; сложные CMP/SPA могут быть частичными. Cookie запроса не пересылаются, query/POST и внешние хосты вне области блокируются; заголовки воспроизводятся частично. Структурированные снимки не являются скриншотами. Не включены анализ PDF/DOCX, сверка РКН, веб-интерфейс, автоматическая юридическая квалификация. Подробности — README и docs/SPEC_CHANGE_1_5.md.
