# Последовательность следующих выпусков

Это порядок работ по согласованной спецификации, не обещание выполнения будущих работ без нового запуска задачи.

| Версия | Объём | Условие начала / окончания |
|---|---|---|
| 0.1.0rc1 | CLI, 7 проверок, HTTP/HTML, JSON/HTML | Текущий пакет; автоматические тесты пройдены |
| 0.1.0 | Закрытие приёмки R1 | WSL2, Docker, 10 сайтов, независимая проверка, Git remote |
| 0.2 | Браузерный CLI, наблюдение cookie-сценариев, сравнение запусков | После стабилизации R1; сохранить работу без браузера |
| 0.3 | Локальный веб-интерфейс | То же ядро, запуск/прогресс/история/отчёты, только loopback |
| 0.4 | Размещённый пилот для нескольких клиентов | Разграничение доступа, очередь, домены, хранение, защита сервиса |
| 0.5 | Опциональные экспертные профили | Отдельное решение; автоматические выпуски не зависят от эксперта |

Исходные ориентиры от старта при 30 продуктивных часах разработчика в неделю: R1 — 3 недели; R2 — 6; R3 — 8; R4 — 12; R5 — 16. Работа в этой сессии не является подтверждением фактически затраченных 90 часов и не закрывает невыполненные условия приёмки.
