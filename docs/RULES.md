# Контракт правил R1

Версия набора `r2-1`, schema `1.1`. Правила C01–C07 сохраняют технический смысл R1. Изменение смысла правила требует новой revision/machine_key.

Все замечания требуют двух согласованных наблюдений. Таймауты, отказ доступа, DNS, ограничения и отличающиеся результаты не превращаются в дефект: `inconclusive`.

| ID | Машинный ключ | Условия / границы |
|---|---|---|
| C01 | protocol-page-v1 | HTML/XHTML, HTTP 200, конечный URL http. Формы с input type=email/tel/password делают риск высоким. HTTPS в action не отменяет факт получения самой страницы по HTTP. |
| C02 | tls-certificate-v1 | SSLCertVerificationError с кодами OpenSSL 9,10,18,19,20,21,62,64. Другие TLS-ошибки не дают красный вывод. В отчёте фиксируется фактический URL соединения, в том числе robots.txt. |
| C03 | document-status-v1 | Явно подписанный документ, одинаковый конечный URL и 404 либо 410 в обоих ответах. Смена 404 на 410 — неоднозначность. |
| C04 | document-loop-v1 | Совпадающая цепочка и повторный URL. Достижение max_redirects не является циклом. |
| C05 | document-downgrade-v1 | Наблюдённый шаг HTTPS→HTTP в завершённой цепочке явно подписанного документа. Незавершённая цепочка — inconclusive. |
| C06 | form-action-v1 | У формы есть типизированное поле, явно задан action или формаction кнопки отправки. Учитываются base, относительные URL, form=id. Пустой/отсутствующий action не даёт этого замечания. method=dialog исключён. JavaScript не выполняется. |
| C07 | document-empty-v1 | HTTP 200 и длина тела после декодирования 0, MIME HTML/XHTML/plain/PDF. Пробелы, JS-каркас, 204, неизвестный MIME, превышенный лимит не равны пустому документу. |

Точные подписи (регистр и повторные пробелы нормализуются; допустимы внешние кавычки/пунктуация):

- политика обработки персональных данных;
- политика в отношении обработки персональных данных;
- политика конфиденциальности;
- согласие на обработку персональных данных.

Используется текст `<a>`, aria-label либо title. URL/имя файла с privacy/policy/consent создаёт только кандидата инвентаризации. Морфология, синонимы и OCR не используются.

Состояния: `pass`, `fail`, `not_applicable`, `not_checked`, `inconclusive`. Пропущенные до выполнения проверки получают `not_checked`; неубедительные наблюдения — `inconclusive`.
Покрытие: pass+fail / все исходы кроме not_applicable. В знаменатель включаются известные пропущенные объекты. Показатель не относится ко всем страницам сайта.

Правовые профили и правила B01–B06: [SPEC_CHANGE_1_5.md](SPEC_CHANGE_1_5.md). Каждая проверка содержит технический исход и отдельный правовой статус.
