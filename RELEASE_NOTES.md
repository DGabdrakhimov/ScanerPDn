# R2 0.2.0rc2 — 15.10.2026

Исправленный тестовый кандидат по результатам прогона rc1. Обновление: UPDATE_R2.md; подробная инструкция: README.md.

1. Исправлен потоковый расчёт бюджета: накопленный размер ответа больше не сравнивается с повторно уменьшаемым остатком общего бюджета.
2. Разделены ошибки общего бюджета, квоты попытки и размера ответа. Добавлены `--browser-total-mib` (100), `--browser-attempt-mib` (25), `--browser-response-mib` (8). По умолчанию 300 запросов и 300 секунд. HTML не более 2 МиБ или меньшего лимита ответа.
3. Все запланированные попытки S0–S3 присутствуют в отчёте, включая незапущенные. Показаны причины и невыполненные действия. При потере наблюдений результат действий считается неизвестным.
4. C01/C06 не применяются к HTTP 200 PDF, подтверждённому двумя попытками. Неизвестные типы и смена PDF/HTML остаются неопределёнными. Машинные ключи C01/C06 изменены на v2.
5. Диагностика кнопок, ссылок, checkbox/radio, ARIA-элементов и select: видимость, подпись, связь с формой, поддержанный тип, контекст cookie, неоднозначность. Доступны открытые shadow DOM. Безопасный список автоматических нажатий не расширен.
6. В HTML добавлена таблица «норма — требование — уровень связи — правила — технические результаты — правовой вывод». Используются сохранённые правовые блоки; нормы в старые отчёты задним числом не добавляются.

Повторная проверка восстановленного кода: 281 Python-тест, 280 пройдены, один Chromium-тест пропущен; 10 отдельных JavaScript-проверок с моделью DOM пройдены. Полный браузерный прогон rc2 пока не подтверждён. Успешный запуск Chromium в пользовательской WSL относится к rc1. Увеличенные бюджеты не гарантируют выполнение неподдержанных сценариев.

Схема JSON 1.1, набор правил r2-2. R1 работает отдельно без Playwright. Пользовательские отчёты и содержимое приложенного архива в публичный Git не включены. Пакет остаётся кандидатом до браузерной приёмки.
