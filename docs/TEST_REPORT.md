# Проверка 0.2.0rc2 после восстановления среды

Дата: 15.10.2026. Linux / Python 3.12.14. Результаты предыдущей прерванной сборки не использованы вместо повторной проверки.

- Python unittest: 281 тест, 280 пройдены, один браузерный тест пропущен. Журнал: test-run-r2-rc2.txt.
- JavaScript: 10 проверок shipped consent_actions.js с моделью DOM, включая единственное/неоднозначное совпадение, скрытые/отключённые элементы, форму, ссылку, ARIA checkbox, отсутствующий cookie-контекст, неподдержанную подпись и отсутствие элементов. Это не тест настоящего Chromium.
- Проверены потоковый бюджет, различение ошибок, восстановление квоты попытки, PDF/HTML/неизвестный MIME, планирование всех попыток, причины и невыполненные действия, потеря наблюдений, приватность, нормативная таблица и совместимость R1.
- Проверены сборка wheel, установка в чистое окружение, версия/диагностика, комплектность JS-ресурсов, JSON Schema и генерация отчёта с новой таблицей.

Полный Chromium-прогон rc2 в среде сборки не выполнен. Пропуск интеграционного теста не равен его прохождению. Успешное выполнение S0 на пользовательской WSL подтверждено только для rc1. До стабильного выпуска нужны реальные браузерные тесты и пользовательский прогон rc2. Новый сайт i.fors.ru из среды сборки не сканировался.

Старые журналы test-run-r2.txt, test-run-rc2.txt и test-run.txt относятся к прежним выпускам. Контейнерный R2 и Python 3.14.4 здесь не проверены.
