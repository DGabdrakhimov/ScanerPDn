# Компоненты и распространение

Время выполнения: Python 3.11+ и стандартная библиотека; сторонние Python-зависимости не требуются. Проверенные версии Python/OpenSSL и метаданные лицензий сборочных компонентов: `docs/COMPONENTS.json`.
CPython распространяется под лицензией PSF; сборочные инструменты не входят в wheel как зависимости. Wheel содержит только код PDScan и JSON Schema.
Лицензия публичного распространения самого проекта пока не выбрана владельцем проекта. Этот файл не предоставляет сторонним лицам отдельную открытую лицензию. При публикации репозитория определите режим доступа и лицензию.
Ключи в tests/fixtures/tls — только открытые тестовые данные. В пакет не должны входить рабочие пароли, токены, ключи или результаты сканирования клиентских сайтов.
